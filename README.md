Cybersecurity write-ups and notes by **0xtonyr**, built with [Jekyll][jekyll]
and the [Chirpy][chirpy] theme and hosted on GitHub Pages.

of machines and CTF challenges, demonstrated TTPs, methodology, tooling, and the
reasoning behind each step.
